# Instructions

## Project Overview

This project is a PDF Merger Tool – a lightweight Streamlit application built with Python to merge multiple PDF files using a drag-and-drop web interface.

## AI Assistant Guidelines

- Always ensure code is compatible with Python 3.13+ and Streamlit.
- Prioritize using `pypdf` for PDF manipulation.
- When running the app locally on Windows, always recommend running via `python -m streamlit run app.py` due to a known `uv` issue with canonicalizing script paths on Windows.
- Ensure the user interface remains simple and intuitive.
