📄 PDF Merger Tool

A lightweight Streamlit web app to merge multiple PDF files — runs locally, drag & drop interface, your files never leave your machine.

Python Streamlit pypdf Local-first

✨ Features

  • 🖱️ Drag & drop PDF upload
  • ⚡ Fast merging via pypdf
  • 🔒 Files stay on your machine
  • 📥 One-click download of merged PDF

🚀 Quick Start

git clone https://github.com/Advirao/pdfmerge.git
cd pdfmerge
uv sync
streamlit run app.py

Then open http://localhost:8501 in your browser.
